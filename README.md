# Samuel Olowolafe Portfolio

This is Samuel Olowolafe's professional portfolio prepared for GitHub Pages. The separate AIL 601 academic portfolio is linked through the Philosophy of Instructional Technology section.

The portfolio includes a dedicated `engagement.html` page for outreach, conference presentations and professional learning, and publications or scholarship. New records can be added to the relevant subsection without expanding the homepage.

## Publish on GitHub Pages

1. Open the existing public repository named `Samuel-Olowolafe-Portfolio` under the `opsam9111` GitHub account.
2. Upload every file and folder from this package to the repository root. `index.html` must remain at the root, not inside another folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub completes deployment, visit `https://opsam9111.github.io/Samuel-Olowolafe-Portfolio/`.

The upload must include `translations.js`, `refinements-translations.js`, and `accessibility.js`. These files provide English, French, and Spanish display options, standard/soft/high-contrast modes, and browser-based read-aloud controls. Available speech voices depend on the visitor's browser and operating system.

## Before publishing

- Confirm the project links open correctly.
- Replace or expand any project description when new evidence becomes available.
- Keep the CV as “being updated” until a current version is ready.
- Do not upload private immigration documents, home addresses, phone numbers, student records, or referee contact details.
